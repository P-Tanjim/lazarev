# LAZAREV. — Award-Winning Agency Website Clone 🪀

A high-performance, award-winning UI/UX & digital product design agency website clone inspired by **[Lazarev. Agency](https://www.lazarev.agency/)**. Built with clean HTML5, custom CSS3, and powerful JavaScript animations using GSAP, ScrollTrigger, and Locomotive Scroll.

🔗 **Live Demo:** [https://p-tanjim.github.io/lazarev/](https://p-tanjim.github.io/lazarev/)

---

## 🌟 Features & Highlights

- **✨ Smooth Inertia Scrolling:** Integrated with **Locomotive Scroll** and **GSAP ScrollTrigger** proxy for fluid, momentum-based scrolling.
- **🎬 Interactive Showreel & Fullscreen Video:** Clickable play overlay that expands into a smooth, border-radius animated full-screen video modal.
- **🖼 Cursor-Tracking Hover Preview:** Interactive image preview cards that follow cursor movements dynamically across section elements.
- **🎥 Dynamic Video Playback on Hover:** Seamless video playback triggers on mouse enter/leave across project case studies.
- **🧭 Dynamic Animated Navigation Bar:** Hover-expandable navbar featuring staggered text reveal timelines.
- **🔄 Infinite Brand Logo Marquee:** Smooth, continuous horizontal scrolling ticker displaying client logos.
- **📂 Accordion & Hover Overlay UI:** Custom HTML5 `<details>` accordions complemented by directional slide hover overlays.
- **⚡ GSAP Scroll-Triggered Text Animations:** Typography and layout elements that animate in sync with scroll position.

## 🚀 Getting Started

No build tools or bundlers required! You can run this project locally in seconds.

### 1. Clone the Repository
```bash
git clone https://github.com/p-tanjim/lazarev.git
cd lazarev
```

### 2. Open in Browser
- Simply double-click `index.html` or open it with your browser.
- Alternatively, use **Live Server** extension in VS Code for the best experience with local video asset loading.
